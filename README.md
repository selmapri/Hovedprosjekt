# Norske helseinstitusjoner

Python-prosjekt med fokus på uthenting og bearbeiding av data om helseinstitusjoner i Norge fra to datakilder:

- [OpenCage Geocoding API](https://opencagedata.com/)
- [data.norge.no](https://data.norge.no/)

## Prosjektstatus

Under utvikling. Foreløpig fokuserer prosjektet på datauthenting. Databearbeiding, integrering og analyse er ennå ikke utviklet.

## Teknologier

- Python
- REST API-er
